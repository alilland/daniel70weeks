# Daniel 70 Weeks

A Ruby CLI tool for exploring the chronology of the "70 weeks" prophecy in Daniel 9 using rigorous, transparent day-count arithmetic.

## Quick Start

```bash
make install    # Install dependencies
make run        # Run the CLI
make test       # Run tests
```
